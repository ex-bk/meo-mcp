# EXBANK MEO 連携（@exbk/meo-mcp）

EXBANK MEO 管理ツールに入っているお店のデータ（クチコミ・順位・月次レポートなど）を、Claude・Cursor・ChatGPT などの AI に「読ませる」ため、そして投稿やクチコミ返信の**下書きを作らせる**ため、さらに**店舗情報（説明文・営業時間・サービス・写真など）の書き換え、SNS 投稿の予約、LINE 配信の依頼**をパソコンの AI から進めるためのつなぎ込み用プログラムです。

- 鍵の権限は2つです。**読み取りのみ**（読むだけ）と、**書き込みまで**（下書き・店舗情報の変更・SNS 投稿・LINE 配信の依頼ができる）。
- 書き込みの流れは、MEO 管理ツールの画面と同じです。鍵を作った人に**承認者が設定されていれば、すべて「承認待ち」に入り**、店舗の管理者（または承認者）が「承認管理」で承認したときだけ Google や SNS に反映されます。**承認者がいない人（本人承認）が作った鍵**では、店舗情報の変更（説明文・営業時間・サービス・写真など）と SNS の予約は、**その場で反映されます**。LINE の一斉配信は、つねに承認待ちです。
- 読み取りのみの鍵では、何も書き換えられません。クチコミの削除や、鍵の操作はできません。
- 料金は、MEO 管理ツールのプランに含まれています。追加の費用はかかりません。

## 1. 鍵を作る（管理者の方）

1. MEO 管理ツールにログインします。
2. 「店舗設定」→「AI 連携」タブを開きます。
3. 「鍵を作る」を押し、名前・権限（読み取りのみ／書き込みまで）・使う店舗・有効期限（30日／90日／1年）を選びます。来店アンケートの回答を AI に見せたいときだけ、アンケートを含めるにチェックを入れます。投稿の下書きや店舗情報の書き換えを AI にさせたいときは、権限を「書き込みまで」にします。あなたに承認者が設定されている場合、書き込みはすべて承認待ちになります。
4. 表示された鍵をコピーします。**鍵が表示されるのはこの1回だけ**です。

### 運営者の方（代行の全店舗を扱う鍵）

EXBANK の運営者は、店舗ごとの鍵とは別に、**代行プランの全店舗**を一度に扱える鍵を作れます（運営者の名簿に入っている人だけ）。

1. 運営者マスター（`/apps/meo/master`）にログインし、左のメニューの「連携鍵」を開きます。
2. 「鍵を作る」を押し、名前・権限（読み取りのみ／書き込みまで）・有効期限（30日／90日／1年）を選びます。対象は代行プランの全店舗です。
3. 表示された鍵をコピーします。**表示されるのはこの1回だけ**です。つなぎ方は、下の「2. つなぐ」と同じです。
4. 一覧で、鍵ごとの最終使用・今日の呼び出し回数・今日の書き込み回数を確認でき、「失効」ですぐに止められます。作成と失効は運営者マスターの操作ログに残ります。

- 運営者の鍵で使える店舗は、プランが代行つきの会社の店舗だけです。`locations_list` で見える店舗が対象です。
- 運営者の鍵だけが使える `get_work_queue`（代行プランの作業待ち）があります。「今週、代行で手を付ける店舗を出して」のように話しかけます。
- 有効な運営者の鍵は10本までです。書き込みの鍵では、鍵ごとの1日の上限（既定30回、運営者マスター「診断ロジック」の「AI 連携：書き込みの 1 日の上限」で変更）が、作った時点の値で固定されます。
- 運営者の鍵で他社の店舗に書き込んだものは、すべてその会社の承認待ちに入ります。反映は、その店舗の管理者（または承認者）が承認したときだけです。
- `bulk_apply` で、複数店舗（30店舗まで）に同じ変更（説明文の差し替えなど）を一括で承認待ちに入れられます。

## 2. つなぐ

以下の `ここに鍵` を、手順1でコピーした鍵に置き換えてください。Node.js（18 以上）が入っている必要があります。

### Claude デスクトップ

設定 → 開発者 → 「設定を編集」で設定ファイルを開き、次を入れて保存し、Claude を再起動します。

```json
{
  "mcpServers": {
    "exbank-meo": {
      "command": "npx",
      "args": ["-y", "@exbk/meo-mcp"],
      "env": { "EXBK_MEO_API_KEY": "ここに鍵" }
    }
  }
}
```

### Claude Code

```bash
claude mcp add exbank-meo --env EXBK_MEO_API_KEY=ここに鍵 -- npx -y @exbk/meo-mcp
```

鍵を使って直接つなぐこともできます（プログラムの導入は不要）。

```bash
claude mcp add --transport http exbank-meo https://exbk.jp/api/meo/mcp --header "Authorization: Bearer ここに鍵"
```

### Cursor

設定の「MCP」から追加するか、`~/.cursor/mcp.json`（そのプロジェクトだけなら `.cursor/mcp.json`）に次を入れます。

```json
{
  "mcpServers": {
    "exbank-meo": {
      "command": "npx",
      "args": ["-y", "@exbk/meo-mcp"],
      "env": { "EXBK_MEO_API_KEY": "ここに鍵" }
    }
  }
}
```

### ChatGPT（開発者モードのコネクタ）

ChatGPT は自分のパソコンのプログラムを起動できないため、インターネット上の入口に直接つなぎます。

1. 設定 → コネクタ → 詳細設定で「開発者モード」をオンにします。
2. 新しいコネクタを作り、次を入れます。
   - URL：`https://exbk.jp/api/meo/mcp`
   - 認証：ヘッダー `Authorization` に `Bearer ここに鍵`（Bearer のあとに半角スペース、そのあとに鍵）

画面の項目名はバージョンによって違うことがあります。ヘッダーを入れる欄が無い場合は、ChatGPT 側の対応を待つか、Claude などをお使いください。

### git から直接使う（npm を使わない場合）

```bash
npx github:ex-bk/meo-mcp
```

上の設定例の `"args": ["-y", "@exbk/meo-mcp"]` を `"args": ["-y", "github:ex-bk/meo-mcp"]` に置き換えると、同じように使えます。初回は組み立てのために少し時間がかかります。

### 接続先を変えたいとき

環境変数 `EXBK_MEO_URL` で変えられます（既定は `https://exbk.jp`）。ふつうは設定不要です。

## 3. 使えるツール

つないだあと、AI に話しかけるだけで使われます。

| ツール | できること | 話しかけの例 |
|---|---|---|
| `locations_list` | 見られる店舗の一覧 | 「MEO の店舗一覧を出して」 |
| `reviews_list` | クチコミの一覧（星・返信の有無で絞れる） | 「返信していないクチコミを見せて」 |
| `basic_get` | 店名・住所・営業時間・カテゴリ・説明文 | 「登録されている営業時間を教えて」 |
| `performance_get` | 表示回数・通話・ルート検索・サイト訪問 | 「この30日の通話の回数は、前の期間と比べてどう？」 |
| `rank_get` | Google マップの検索順位の推移 | 「『渋谷 カフェ』の順位は先月からどう動いた？」 |
| `reviews_analysis_get` | クチコミの分析（星の分布・よく出る言葉・良い点と課題） | 「お客様が褒めている点と不満の点をまとめて」 |
| `report_get` | 月次レポート（既定は先月） | 「先月のレポートを店主向けにやさしく説明して」 |
| `aio_get` | AI に聞いたときにお店が答えに出るか | 「AI の答えにうちの店は出ている？」 |
| `survey_answers_get` | 来店アンケートの回答（鍵で許可したときだけ） | 「最近のアンケートの声を要約して」 |
| `approvals_list` | 承認待ち・差し戻しの返信や投稿 | 「承認待ちはいくつある？」 |
| `get_store_materials` | 投稿文や書き換えの材料を1回で（説明文・カテゴリ・電話・営業時間・属性・サービス・写真の枚数・狙うキーワード・直近の投稿とSNS投稿・直近30日の数字・クチコミ・LINE の友だち数・書くときの決まり） | 「この店の材料を読んで」 |
| `get_rank_summary` | キーワード別の最新の平均順位と、上位3位に入った地点の割合 | 「順位の最新を要約して」 |
| `get_instagram_insights` | Instagram のフォロワー推移（連携済みの店舗だけ。未連携は not_linked） | 「Instagram のフォロワーは増えてる？」 |
| `get_seo_diagnosis` | SEO 調査の新しい診断（実順位・点数項目・今週やること3つ） | 「SEO 診断の結果を見せて」 |
| `list_sns_posts` | SNS 横断の投稿と、宛先ごとの状態（承認待ち・予約済み・公開済み） | 「予約している投稿を一覧にして」 |

`performance_get` は、`from`／`to`（YYYY-MM-DD）で期間を指定できます（今月・先月の数字の要約に使います）。

**書き込みのツール**（権限が「書き込みまで」の鍵にだけ表示されます。承認者がいれば承認待ち、いなければ本人承認でその場で反映されます）

| ツール | できること | 話しかけの例 |
|---|---|---|
| `create_post_draft` | 最新情報の投稿を下書きにして承認待ちへ（種類・本文・写真・ボタン・公開希望日時）。つねに承認待ち | 「今週の投稿を3本下書きして」 |
| `create_review_reply_draft` | クチコミへの返信を下書きにして承認待ちへ（返信済みのクチコミには作れません）。つねに承認待ち | 「未返信のクチコミに返信案を作って、下書きに入れて」 |
| `schedule_post` | この連携で作った下書きに、公開希望日時を設定（承認待ちのまま） | 「その投稿は来週月曜の10時にして」 |
| `update_basic_info` | 説明文・メインと追加のカテゴリ・電話・ウェブサイト・営業時間・特別営業時間・その他の営業時間・属性・SNS リンクの書き換え | 「説明文を AI 導入支援の訴求に変えて」 |
| `search_categories` | カテゴリの候補探し（何も書き換えません） | 「『コンサルティング』に近いカテゴリを探して」 |
| `update_services` | サービス項目の**全件置き換え**（`replace_all: true` が必要） | 「サービスを次の8件にして」 |
| `add_photo` | 画像の URL とカテゴリを指定して写真を追加（https・JPEG/PNG・10KB〜5MB） | 「この画像を店内の写真として追加して」 |
| `create_sns_post` | Google・Instagram・TikTok・Threads・LINE への投稿を、宛先別の本文（省くと AI が書き分け）と予約日時つきで作成 | 「この内容を Google と Instagram に、来週月曜の10時で」 |
| `cancel_sns_post` | 予約・承認待ちの投稿の取り消し | 「その予約を取り消して」 |
| `create_line_broadcast` | LINE の一斉配信を作って承認待ちへ（送るのは承認後） | 「友だち全員に、来月のお知らせを配信して」 |
| `create_line_autoreply` | LINE の自動返信（キーワード → 返信文）を登録 | 「『営業時間』と送られたら、営業時間を返信して」 |
| `create_line_scenario` | LINE のステップ配信を下書きで保存（公開は画面で承認を依頼） | 「友だち追加の3日後にお礼を送るステップ配信を下書きして」 |

運営者の鍵（EXBANK の運営者だけが発行できます）では、さらに `get_work_queue`（代行プランの作業待ち）と、`bulk_apply`（複数店舗に同じ変更を、承認待ちとして一括で入れる）が使えます。
そのほか、「今週のやること」「未返信クチコミの返信方針」「先月のふりかえり」「投稿を3本下書きする」「今月の数字の要約」のひな形（プロンプト）が使えます。

読むのは保存済みのデータです。画面で一度も開いていない項目は「まだ取得していません」と返ります。クチコミなどお客様が書いた文は、AI には「データ」として渡され、中に書かれた命令には従わないようになっています。

## 4. 使い方の例

### 「投稿を3本下書きして」（権限が「下書きの作成まで」の鍵）

ChatGPT（開発者モードのコネクタをオンにしたチャット）でも、Claude デスクトップ／Claude Code でも、同じ言い方で使えます。

> 「MEO の店舗一覧から『◯◯店』を選んで、get_store_materials で材料を読み、来週ぶんの最新情報の投稿を3本下書きして。まず本文を見せてね。」

AI は材料（直近の投稿・最近のクチコミ・書くときの決まり）を読み、3本の本文を見せます。返事で「1と3を承認待ちに入れて」と伝えると、`create_post_draft` で承認待ちに入ります。公開するには、店舗の管理者が MEO 管理ツールの「承認管理」で承認します。公開日時を決めたいときは「3本目は来週月曜の10時に」と伝えます（`schedule_post`）。

### 「今月の数字を要約して」（読み取りのみの鍵でも使えます）

> 「◯◯店の今月（1日から昨日まで）の数字と順位、新しいクチコミを読んで、店主向けにやさしく要約して。来週の一手も1つ添えて。」

`performance_get`（期間を指定）・`get_rank_summary`・`reviews_list` が使われます。

### Claude Code から店舗情報を書き換える例

Claude Code でつないだあと（「2. つなぐ」の Claude Code の手順）、次のように話しかけます。**書き換える前に、必ず現在の内容と新しい内容を見せてもらい、確かめてから進めてください。**

#### 例1：説明文を、AI 導入支援の訴求に変える

> 「MEO の店舗一覧から『◯◯事務所』を選んで、get_store_materials で今の説明文・カテゴリ・サービスを読んで。説明文を『中小企業の AI 導入支援』が伝わる内容に直して（750字以内、誇大な表現なし）。今の文と新しい文を並べて見せて、OK と返事したら update_basic_info で反映して。」

Claude Code は材料を読み、新旧の説明文を並べます。「OK」と返すと `update_basic_info`（`description`）が呼ばれます。結果の `status` が `applied` なら、あなたが承認者のいない人なので、Google に反映済みです。`pending_approval` なら、承認管理で管理者または承認者が承認したときに反映されます。

#### 例2：サービスを8件入れる

> 「サービスを次の8件に置き換えて。①AI 導入の無料相談（無料）②業務の洗い出し診断（55,000円）③生成 AI 研修（110,000円）④…（8件）。今あるサービスも get_store_materials で確かめて、残すものは含めてね。一覧を見せて、OK と返事したら update_services（replace_all: true）で入れて。」

サービスは**全件の置き換え**です。残したいものも含めて渡してもらうために、今の一覧を先に確かめます。カテゴリを省くと、店舗のメインのカテゴリが使われます。

#### 例3：投稿を4本予約する

> 「get_store_materials で材料を読んで、来月の毎週月曜10時に出す投稿を4本書いて。Google と Instagram の両方（Instagram は写真が必要：https://example.com/photo1.jpg …）。4本の本文を宛先別に見せて、OK と返事したら create_sns_post を4回呼んで予約して。」

本文を渡さない宛先は、素材から AI が書き分けます。承認者がいる場合は、4本とも承認待ちに入り、承認管理で承認されると予約になります。いない場合は、その場で予約されます。取り消すときは「その4本を取り消して」と話しかけます（`list_sns_posts` → `cancel_sns_post`）。

### 書き込みの鍵の注意

- 「書き込みまで」の鍵は、AI が承認待ちを増やせる鍵です。**承認者がいない人が作った鍵では、店舗情報の変更と SNS の予約がその場で反映されます。** 必要な人にだけ渡し、読み取りだけで足りる人には「読み取りのみ」の鍵を作ってください。
- 書き込みには、鍵ごとに1日の上限があります（既定30回）。店舗ごとに、この連携で作った承認待ちは投稿20件・返信50件までです。
- AI に下書きを入れさせる前に、本文を必ず自分の目で確かめてください。誇大な表現・効果の断定・クチコミの依頼は、システム側でも断ります。
- 営業時間は7曜日すべて、サービスは全件を渡す形です（指定しない曜日が定休日になったり、渡さなかったサービスが消えたりする事故を防ぐため）。
- 最新情報の下書き（`create_post_draft`）の写真は、MEO 管理ツールにアップロードした自社の写真の URL だけ使えます。`add_photo` と `create_sns_post` の写真は、https の画像 URL を渡すと、MEO 管理ツールの置き場に取り込まれます（JPEG／PNG、10KB〜5MB。社内のアドレスなど、公開されていない場所の画像は取り込めません）。
- 誰が何を作ったかは、MEO 管理ツールの操作ログに残ります（経路は「AI 連携」と表示されます）。

## 5. 鍵の取り扱い

- 鍵はパスワードと同じです。チャット・メール・公開の場所（GitHub など）に貼らないでください。
- 設定ファイルに書いた鍵は、そのパソコンの持ち主だけが見られる状態にしてください。
- 使いすぎを防ぐため、1日500回まで、1分に60回を超えると鍵が自動で失効し、管理者にメールが届きます。
- 取り消し方：「店舗設定 → AI 連携」の一覧で、その鍵の「失効」を押します。すべての鍵を止めたいときは「全部の鍵を今すぐ失効」を押します。心当たりがないときや、パソコンをなくしたときは、すぐに失効させてください。
- 「直近の操作」で、いつ・どの鍵で何が読まれたかを確認できます。

## 6. うまくいかないとき

| 表示 | 原因と対処 |
|---|---|
| 鍵が設定されていません | 設定の `EXBK_MEO_API_KEY` が空です。鍵を入れてください |
| 鍵が使えません（401） | 鍵の入れ間違い、失効、期限切れです。鍵を作り直してください |
| 今日の回数の上限（429） | 1日500回に達しました。日本時間の0時に戻ります |
| 今日の書き込みの上限（429） | 鍵ごとの1日の書き込み回数に達しました。日本時間の0時に戻ります |
| `[E_READ_ONLY]` | 読み取りのみの鍵です。「書き込みまで」の鍵を作り直してください |
| `[E_PLAN_REQUIRED]` | 無料登録のままでは、Google や SNS への反映ができません（承認者がいる場合の承認待ちまでは進めます）。店舗設定 →「プランと支払い」から始めてください |
| `[E_UNAVAILABLE]` | 投稿先（Instagram・TikTok・Threads・LINE・Google）が未連携です。MEO 管理ツールで連携してください |
| `[E_PHOTO_*]` | 画像を取り込めません（https でない・大きさ・形式・取得できない）。URL と画像を確かめてください |
| `[E_BANNED_WORDS]` | 本文に使えない言葉があります。書き直してもらってください |
| `[E_TOO_MANY_PENDING]` | 承認待ちが上限に達しています。「承認管理」で処理してください |
